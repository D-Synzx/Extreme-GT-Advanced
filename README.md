# Extreme-GT Advanced
[![Telegram](https://img.shields.io/badge/Telegram-2CA5E0?style=for-the-badge&logo=telegram&logoColor=white)](https://t.me/synzxstuff)

For OxygenOS, ColorOS, RealmeOS 


Use [**KernelSU-Next**](https://github.com/KernelSU-Next/KernelSU-Next) for better performance and stability. 

<details><summary><big>Features</big></summary>
<ul>
 <li>A simple module that turns off most logd（Including lsposed-it logd)</li>
 <li> Changes the temperature limit to 45 (can be modified in service.sh, +15 is the temperature wall)</li>
 <li> Removes the floating window limit</li>
 <li> Turns off battery heating</li>
 <li> More apps HDR support (/my_product/vendor/etc/Modify the directory)</li>
 <li> Simple hidden BL</li>
 <li> Turn off some temperature-induced restrictions</li>
 <li> Turn on DC dimming</li>
 <li> This function is only available in IN</li>
    <ul>
     <li> Devices outside of this region need to modify 23861 in /odm/etc/temperature_profile/ to the code of their region, like: China 23851</li>
